OFFGRID 1.4.0 — WINDOWS RESOURCE PROFILES

IMPORTANTE
- Esta atualização é otimizada para Windows 10/11 x64.
- No Linux/macOS, Chat e Agente continuam funcionando.
- Fora do Windows, apenas a medição avançada de VRAM e o perfil adaptativo orientado pelas APIs do Windows ficam indisponíveis.
- Não é necessário baixar novamente os modelos 3B e 7B.

RECURSOS INCLUÍDOS
1. RAM total, livre e em uso.
2. RAM precisa do processo isolado do motor.
3. Consulta de VRAM no Windows:
   - nvidia-smi quando disponível;
   - informações do Windows como fallback.
4. Perfil automático por modelo e computador.
5. Tentativas progressivas de GPU Layers.
6. Fallback final para CPU.
7. Histórico de perfis bem-sucedidos e falhas.
8. Processo do node-llama-cpp separado do Extension Host.
9. Reinício do motor sem reiniciar o VS Code.
10. Painel de RAM, GPU e memória do motor no chat.

LIMITAÇÃO CONHECIDA
O processo do motor foi separado e a base para integração entre IDEs foi preparada. O compartilhamento simultâneo do mesmo processo entre VS Code e IntelliJ ainda não está ativado nesta versão; isso exigirá uma atualização correspondente do OffGrid IntJ.

PASSO A PASSO

1. Feche VS Code, GitHub Desktop e terminais abertos na pasta do Offgrid.

2. Faça uma cópia da pasta do repositório, por exemplo:
   C:\Users\rafae\Documents\GitHub\offgrid-backup-1.3.0

3. Extraia offgrid-update-v1.4.0.zip.

4. Copie todo o conteúdo interno da pasta extraída para:
   C:\Users\rafae\Documents\GitHub\offgrid

5. Confirme "Substituir os arquivos no destino".

6. Abra PowerShell na pasta do repositório e execute:
   node scripts/apply-v1.4-update.js

7. Execute:
   npm run check

8. Execute:
   npm test

Resultado esperado:
   tests 17
   pass 17
   fail 0

No Windows, o teste de symlink pode ser ignorado sem impedir a atualização.

9. Execute:
   npm run package

Arquivo esperado:
   offgrid-1.4.0.vsix

10. No GitHub Desktop, faça commit:
    Adiciona perfis de RAM VRAM e motor isolado

11. Clique em Push origin.

12. No GitHub, crie uma Release:
    Tag: extension-v1.4.0
    Título: Offgrid 1.4.0 — Recursos do Windows

13. Anexe offgrid-1.4.0.vsix e publique.

NOVOS COMANDOS
- Offgrid: Mostrar RAM e VRAM
- Offgrid: Reiniciar Processo do Motor
- Offgrid: Limpar Perfil Automático de Hardware

TESTE NO COMPUTADOR DA EMPRESA
1. Instale offgrid-1.4.0.vsix.
2. Reinicie o VS Code.
3. Abra o painel Offgrid.
4. Confirme que o painel mostra RAM e Motor.
5. Execute "Offgrid: Mostrar RAM e VRAM".
6. No Windows com NVIDIA, confirme que aparece a RTX e a memória disponível.
7. Selecione o Qwen 3B e confirme o carregamento.
8. Selecione o Qwen 7B. O Offgrid deve escolher camadas parciais ou CPU se a VRAM não for suficiente.
9. Execute "Offgrid: Reiniciar Processo do Motor" e confirme que o modelo pode ser recarregado sem reiniciar o VS Code.
