OFFGRID 1.2.0 — ATUALIZAÇÃO

Esta atualização corrige o carregamento silencioso do modelo e adiciona:
- canal de logs Offgrid;
- recarga automática e comando Recarregar Modelo;
- detecção automática de GPU com fallback para CPU;
- arquivo ativo/fixado como ponto de partida;
- lista dos arquivos propostos no chat;
- diff visual vermelho/verde antes de salvar;
- botões Aceitar alterações e Rejeitar;
- backup e comando de desfazer após aceitar.

COMO APLICAR NO COMPUTADOR PESSOAL

1. Feche o VS Code, GitHub Desktop e terminais da pasta Offgrid.
2. Faça uma cópia de segurança da pasta do repositório.
3. Extraia este ZIP.
4. Copie todo o conteúdo extraído para a pasta do repositório Offgrid.
5. Quando o Windows perguntar, escolha Substituir os arquivos no destino.
6. Abra um PowerShell na pasta do repositório.
7. Execute:

   node scripts/apply-v1.2-update.js
   npm run check
   npm test
   npm run package

8. O arquivo esperado é:

   offgrid-1.2.0.vsix

9. No GitHub Desktop, faça commit e Push origin.
10. No GitHub, crie a tag extension-v1.2.0 e a Release "Offgrid 1.2.0".
11. Anexe offgrid-1.2.0.vsix e publique a Release.

Não execute novamente o workflow dos modelos. O Release models-v1 continua válido.

NO COMPUTADOR DA EMPRESA

1. Baixe offgrid-1.2.0.vsix na nova Release.
2. No VS Code: Extensões → ... → Install from VSIX...
3. Selecione o arquivo e reinicie o VS Code.
4. Confirme a versão 1.2.0.
5. Os GGUF já baixados permanecem na pasta globalStorage e não precisam ser baixados novamente.
6. Execute Offgrid: Recarregar Modelo.
7. Se houver falha, abra Exibir → Saída → Offgrid e copie o log.
