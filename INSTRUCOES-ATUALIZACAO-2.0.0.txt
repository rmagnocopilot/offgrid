OFFGRID 2.0.0 — REESCRITA TYPESCRIPT

1. Faça backup ou confirme que o Git está limpo.
2. Feche o VS Code e terminais abertos no repositório.
3. Extraia este ZIP.
4. Copie todo o conteúdo interno para a raiz do repositório offgrid.
5. Confirme mesclar pastas e substituir arquivos.
6. Abra PowerShell na raiz do repositório.
7. Execute:

   node scripts/apply-v2-update.js
   npm install
   npm run check
   npm test
   npm run package

8. Resultado esperado dos testes: 39 testes ou mais, zero falhas.
9. Resultado esperado do pacote: offgrid-2.0.0.vsix.

TESTE DA INTERFACE SEM MODELO

- Abra o repositório no VS Code.
- Pressione F5.
- Selecione "Executar Offgrid (TypeScript)".
- Na segunda janela, execute "Offgrid: Alternar Modo Visual Simulado".
- Clique no ícone Offgrid na Activity Bar.

MODELOS

Os GGUF existentes não precisam ser baixados novamente. Eles ficam fora do repositório, no globalStorage da extensão.

ATENÇÃO

O npm install é obrigatório porque a nova base adiciona TypeScript e tipos do VS Code como dependências de desenvolvimento.
